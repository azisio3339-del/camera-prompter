# カメラ付きプロンプター

iPhone の横画面で、前面カメラで自分を映して録画しながら、原稿を指定時間でスクロール表示する Web アプリ（PWA）です。
仕様は [SPEC.md](SPEC.md) を参照してください。

素の HTML・CSS・JavaScript だけで動きます。フレームワーク・ビルド工程・外部 CDN・サーバー側の処理は使っていません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 全画面のマークアップ（1 ページで 5 画面を切り替える） |
| `style.css` | レイアウトと見た目 |
| `app.js` | 画面遷移、原稿、スクロール、カメラ、録画、保存 |
| `platform.js` | iOS・Android で分岐が必要な処理（録画形式、保存方法、Wake Lock、カメラの案内文） |
| `manifest.json` | ホーム画面追加用 |
| `sw.js` | Service Worker（全ファイルをキャッシュしてオフラインで動かす） |
| `icons/` | アプリアイコン（180 / 192 / 512px） |
| `SPEC.md` | 実装書（仕様の一次情報） |
| `tools/dev-server.mjs` | 実機確認用のローカルサーバー（アプリ本体には含まれない） |
| `tools/make-icons.mjs` | アイコン生成スクリプト（同上） |

`tools/` は開発用で、配信するのは `tools/` 以外のファイルです。

## 1. PC のブラウザで確認する

```bash
node tools/dev-server.mjs --http
```

`http://localhost:8080/` を開きます。`localhost` は HTTPS でなくてもカメラを使えます。

縦でも横でも動きます。実機に近い大きさで見るなら、横 852 × 縦 393（横画面）か 横 393 × 縦 852（縦画面）くらいのウィンドウで開いてください。

## 2. iPhone 実機で確認する（同じ Wi-Fi のローカルサーバー）

PC と iPhone を同じ Wi-Fi につないでから、PC で次を実行します。

```bash
node tools/dev-server.mjs
```

- 初回は `openssl` で自己署名証明書を `tools/.cert/` に作ります（`openssl` が必要）
- 起動すると `https://192.168.x.x:8443/` のような URL が表示されます
- その URL を iPhone の Safari で開きます
- 自己署名証明書なので警告が出ます。**「詳細を表示」→「この Web サイトを閲覧」** で進んでください
- カメラとマイクの許可を聞かれたら「許可」を選びます

Windows のファイアウォールで Node.js の受信接続を許可するか聞かれたら、「プライベートネットワーク」を許可してください。

**この方式の制限**：証明書の警告を毎回タップで抜ける必要があり、**ホーム画面のアイコンからは起動できません**（全画面起動には警告を抜ける画面がないため）。Service Worker も登録されないのでオフラインでも動きません。アイコン起動まで行きたいときは次の 3 を見てください。

## 3. アイコン起動・オフラインまで確認する（2 通り）

URL バーを消すには、ホーム画面のアイコンから起動する必要があります。そのためには**警告の出ない HTTPS** が要ります。方法は 2 つです。

### 3-A. GitHub Pages に置く（おすすめ）

正式な証明書になるので、警告なし・アイコン起動・Service Worker・機内モード起動まですべて確認できます。将来の配布先としてもそのまま使えます。

1. github.com で空のリポジトリを作る（例：`camera-prompter`。README などは追加しない）
2. このフォルダで次を実行する

```bash
git init -b main
```

```bash
git add . && git commit -m "カメラ付きプロンプター"
```

```bash
git remote add origin https://github.com/<ユーザー名>/camera-prompter.git && git push -u origin main
```

3. リポジトリの **Settings → Pages** で Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
4. 数十秒後に `https://<ユーザー名>.github.io/camera-prompter/` で開ける

> 原稿は端末内（localStorage）にしか保存されず、録画も外部に送られませんが、リポジトリを公開にすると誰でもアプリ自体は開けます。気になる場合は別のホスティングを検討してください（Private リポジトリの GitHub Pages は有料プランが必要です）。

### 3-B. 自己署名証明書を iPhone に信頼させる（GitHub を使わない方法）

PC のサーバーだけで完結します。ただし PC を起動してサーバーを動かしている間しか使えず、**PC の LAN IP が変わると証明書を作り直す**必要があります。

1. `node tools/dev-server.mjs` を起動したまま、iPhone の Safari で `https://<表示された IP>:8443/cert.pem` を開く
2. 「プロファイルがダウンロードされました」→「設定」アプリ →「プロファイルがダウンロードされました」→ **インストール**
3. 「設定」→「一般」→「情報」→ **「証明書信頼設定」** を開き、`camera-prompter-dev` のスイッチを**オン**にする
4. Safari で `https://<IP>:8443/` を開き直すと警告が出なくなる

> これは「この証明書を出すサーバーを信用する」設定です。`tools/.cert/key.pem`（秘密鍵）が他人に渡ると、その人がこの iPhone に対してなりすませます。鍵は外に出さず、不要になったら「設定」→「一般」→「VPN とデバイス管理」からプロファイルを削除してください。

### ホーム画面に追加する

3-A か 3-B で警告が出なくなったら、Safari の共有ボタン →「ホーム画面に追加」。
ホーム画面のアイコンから起動すると全画面になり、URL バーもタブバーも出ません。

**注意**：ホーム画面から起動したときと Safari で開いたときで、カメラの許可は別扱いになります。ホーム画面から初めて起動したときは、もう一度許可を求められます。

## 4. 更新したとき（キャッシュの入れ替え）

Service Worker は全ファイルをキャッシュしているため、ファイルを直しただけでは反映されないことがあります。
配信前に `sw.js` の先頭を書き換えてください。

```javascript
var CACHE = 'prompter-v2';   // v1 → v2 のように上げる
```

古いキャッシュは次回起動時に自動で消えます。
手元で強制的に消したいときは Safari の「設定 →  Safari → 履歴と Web サイトデータを消去」、またはホーム画面のアイコンを削除して追加し直してください。

## 5. アイコンを差し替える

`icons/icon-180.png`・`icon-192.png`・`icon-512.png` を好きな PNG で上書きするだけです。
今入っているのは仮アイコン（黒地に黄色の読むラインマーカーと 3 行の原稿）で、次のコマンドで作り直せます。

```bash
node tools/make-icons.mjs
```

## 6. 操作の流れ

| 操作 | どうなるか |
| --- | --- |
| **原稿枠をタップ** | 枠がそのまま入力欄になる。長押し → ペーストで貼り付け。入力のたびに自動保存 |
| 枠の右上の ✓／枠の外をタップ | 入力を終える |
| **原稿枠を 1 本指でドラッグ** | 枠を移動する |
| **原稿枠を 2 本指でピンチ** | 枠を拡大縮小する（中心はそのまま） |
| **枠の右下のつまみをドラッグ** | 枠の幅と高さを変える（左上は動かない） |
| **ダイヤルをなぞる** | 時間（0:10〜10:00）を 5 秒きざみで決める。横画面は上へ、縦画面は左へなぞると長くなる |
| 文字サイズのアイコン | 文字サイズのスライダーが出る（もう一度押すと閉じる） |
| 赤いシャッター | 3 秒カウントダウン → 録画とスクロールが同時に始まる |
| 録画中の一時停止 | スクロールだけ止まる（録画は続く）。もう一度押すと続きから |
| 録画中の停止（白い輪の中の赤い四角） | 録画を終えて確認画面へ |
| 右下のサムネイル | 直前の録画をもう一度確認する |
| 確認画面の「保存」 | 共有シート →「ビデオを保存」で写真アプリへ |
| 確認画面の「撮り直す」 | 撮影待機に戻る |

カメラ切替ボタンは、カメラが 2 台以上あるときだけ出ます（PC の複数 Web カメラ、iPhone の前面／背面）。つながっているカメラを順に切り替え、選んだカメラは次回も使われます。背面カメラ以外はプレビューも録画も左右反転（鏡と同じ向き）です。

時間は**ダイヤル**で決めます。iPhone のカメラのズームと同じで、画面の端に出ている目盛りの弧をなぞると回り、黄色い針の位置の値が選ばれます。

### 縦画面と横画面

どちらでも撮影・録画できます。向きによってレンズの位置が違うので、画面の作りも変わります。

| | レンズの位置 | 操作列 | 原稿枠の初期位置 |
| --- | --- | --- | --- |
| 横画面 | 左 | 右（幅 104pt） | 左上 |
| 縦画面 | 上 | 下（高さ 118pt）。左から 前回の録画・シャッター・カメラ切替・文字サイズ | 上辺いっぱい・中央寄せ |

時間のダイヤルは、横画面では右端の縦中央、縦画面では下端の横中央に出ます。

**枠の位置と大きさは向きごとに別で覚えます。** 横で合わせた枠を縦にしても崩れませんし、縦で合わせ直しても横の設定は残ります。
時間・文字サイズ・読むライン・前面／背面は共通です。

原稿をたくさん打つときは**縦画面のほうが打ちやすい**です（枠が画面の上にあるので、キーボードが出ても隠れません）。

入力中はレイアウトが動かないようにしてあります。キーボードで画面が狭くなっても、原稿枠の大きさ・位置も、画面の向きも、ボタンの並びも変わりません。
ただし **iOS ではキーボードが画面の一部を覆うこと自体は避けられません**（Web からキーボードの出方は変えられないため）。できるのはページ側を動かさないところまでです。

### URL バーを消すには

iPhone の Safari では、ページ側から URL バーを消すことはできません。**ホーム画面に追加して、そのアイコンから起動する**と全画面になり、URL バーもタブバーも出ません（上の 3 を参照）。

## 8. うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| カメラの映像が出ない | HTTPS か localhost で開いているか。画面の案内に沿って設定アプリで許可する |
| ホーム画面起動だけカメラが出ない | Safari とは別に許可が必要。起動後に出る許可ダイアログで「許可」を選ぶ |
| 録画が保存できない | 共有シートで「ビデオを保存」を選んだか。写真へのアクセス許可を確認する |
| 直したのに反映されない | `sw.js` の `CACHE` のバージョンを上げる（上記 4） |
| 向きが切り替わらない | iPhone の画面回転ロックを解除する |
| 原稿が消えた | iOS は長期間起動しないと端末内のデータを消すことがある。元の文章は手元に残しておく |
